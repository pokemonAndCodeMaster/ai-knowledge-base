# 人工质检验收只读查询链

← [[人工质检验收第一纵切架构枢纽]]、[[人工质检验收第一纵切查询与API设计]]。

## Why

第一纵切把任务聚合、最近非零标注日和日期展开从 Demo 数据改为参数化 PostgreSQL 查询，并保持 Router → Service → Repository → PostgresConnector 依赖方向。

## Who

- `src/api/schemas/acceptance.py` 定义 QuerySpec 和响应；
- `src/manual_qc/acceptance/router.py` 提供 HTTP；
- `AcceptanceQueryService` 组装分页与计算时间；
- `AcceptanceRepository` 负责白名单筛选、排序和聚合 SQL。

同一 Repository 现已增加 SelectionSpec 任务解析、日期可用量查询和 preview 持久化；写操作编排仍由 [[人工质检验收分配预览链]] 负责，不塞进查询 Service。

## Where

- `src/manual_qc/repository.py`
- `src/manual_qc/acceptance/services/query_service.py`
- `src/manual_qc/acceptance/router.py`
- `src/api/schemas/acceptance.py`
