# 配置管理公共模块

本卡记录当前仓库第一版 `src/config` 公共配置模块。它承接 [[质检一站式平台长期架构]] 中的配置中心职责，让 API、数据库和未来业务模块共享同一套运行时配置。

## Why

- 将 `config/application.yaml` 作为默认配置入口。
- 支持 `${ENV:-default}` 形式的环境变量占位，避免把数据库密码等敏感值写入仓库。
- 在没有 PyYAML 的干净环境中也能启动，因此内置了项目所需的极简 YAML 子集解析器。
- 用 `AppSettings`、`ApiSettings`、`PostgresSettings` 把动态配置转成类型化对象。

## Who

- 被 [[PostgreSQL数据库公共模块]] 读取，用于构造 PostgreSQL 连接池参数。
- 被 [[FastAPI应用入口与依赖注入层]] 读取，用于设置 API 标题、版本、CORS 和静态前端目录。

## Where

- `src/config/manager.py`：`ConfigManager`、`get_global_config()`、`reset_global_config()`。
- `src/config/settings.py`：`AppSettings`、`ApiSettings`、`PostgresSettings`。
- `config/application.yaml`：默认运行配置。

## 设计约束

- 配置加载不得在导入时连接数据库。
- 默认配置只能放占位和非敏感默认值；真实密码通过环境变量注入。
- 业务模块只读 `ConfigManager` 或类型化 settings，不直接解析 YAML。
