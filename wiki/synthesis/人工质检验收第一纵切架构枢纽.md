## Review 路径

1. [[人工质检验收第一纵切端到端架构]]：范围、组件图、数据流和文件落点；

## 第一纵切交付范围

- Vue3 + TypeScript + Vite 应用骨架、路由、AppShell；
- FastAPI 人工质检 Router、Schema、Repository、Service 依赖链；
- PostgreSQL 任务表、日快照测试数据和公共查询能力；
- 验收任务聚合、按日展开、筛选、排序和分页 API；
- 统一数据工作台首版：列显隐、筛选、排序、宽度、父子选择、多选操作入口、按日展开、布局状态和一键分析入口；
- 验收中心初版页面与主要点击路径；
- 可重复执行的后端单测、前端组件测试和数据库集成验证。

## 本纵切暂不执行

- 真实 Delta 分配与通过打回；
- 真实 SSO；
- 所有表格高级能力一次性完成；
- 公共卡片市场和复杂指标编辑器。

这些能力必须有接口占位和后续卡片，但不冒充已实现。

## 当前落地状态

- 已初始化 Vue3 + TypeScript + Vite 正式工程；
- 已实现 AppShell、验收路由、开源 DataWorkbench 和 DashboardLayout 骨架；
- 已实现父选子、子取消后父半选、分析面板按需出现和按日展开请求；
- 已实现 FastAPI 查询 Router、Pydantic Schema、Service、参数化 Repository；
- 已增加交付任务、PostgreSQL preview、公共/个人视图配置表；
- 已提供隔离 PostgreSQL fixture 和 `scripts/verify_acceptance_vertical_slice.sh`；
- 已实现 explicit/filtered SelectionSpec、Ratio 配额、PostgreSQL preview 写入/读回和前端结果面板；
- 真实 Delta、SSO、Group/Personal 分配、完整布局 API 和高级表格能力仍在后续阶段。

## 下一轮 Review 与实现顺序

1. GroupSampler、PersonalSampler、验收员池和供应商冲突约束；
2. preview 明细分页、局部排除/覆盖与重新求解；
3. DataWorkbench：列级多类型筛选、单元格编辑、视图配置保存和导出适配器；
4. DashboardLayout：公共/个人布局 CRUD、卡片编辑器和指标注册表；
5. fake Delta 执行、部分失败、重复执行与状态回查；取得真实接口资料后再替换适配边界。
