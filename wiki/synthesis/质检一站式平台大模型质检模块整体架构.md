# 质检一站式平台大模型质检模块整体架构

## 页面工作台补全（2026-07-05）

- [[大模型质检总览信息架构]]：通用能力雷达、专项任务趋势、训练/精标/评测资产；
- [[大模型质检生产任务工作台前端设计]]：顺序通道生产、任务组/case、版本选择、回滚和生成数据集；
- **版本配置**：管理各通道版本，支持创建、编辑、适用范围和引用关系；
- **数据集管理**：数据集规模、场景与多维分布、精标/粗标属性、版本来源；支持图片/视频与 Prompt 文本的 case 预览；
- **模型评测**：创建评测任务，查看单版本分析和多版本对比，结果可下钻到 case；
- 共享底座：[[质检平台统一数据工作台组件设计]]、[[质检平台可配置卡片布局组件设计]]。

生产结果先生成一般数据集，再由数据集管理页分配为训练集、验证集或评测集；生产任务页不提前绑定最终用途。

← 上位平台：[[质检一站式平台顶层架构]]。完整原始设计见 [[09_质检一站式平台大模型质检模块整体架构|NotebookLM 大模型质检整体架构原文]]。

大模型质检业务当前处于 POC 演进期，业务总览的主线是实验效果、能力成熟度和数据/评测资产，而不是版本交付。生产任务与版本配置继续作为工程样板域；六通道生产 Pipeline 是外部事实源和状态来源，不在本模块重复设计。

## POC 业务总览

- 基模型当前最佳 Benchmark 与目标差距；
- Agent 体系当前最佳 Benchmark 与目标差距；
- 已达上线、接近上线、攻关中的能力维度；
- 当前实验、关键阻塞和下一里程碑；
- 训练集、验证集、评测集规模、覆盖和建设进度。
- 基模与 Agent Benchmark 的时间趋势，以及相对上线阈值的差距；
- 按能力维度展示已上线水准、接近上线和攻关中分布。

Benchmark 名称、上线阈值和能力维度必须接入真实定义，在确认前不得用虚构精确数字替代。

总览完整信息架构见 [[大模型质检总览信息架构]]：通用能力使用最强模型/Agent 体系的外显能力雷达图，专项任务分别显示实验趋势，数据资产分为通用集、精标集和评测集。

## 两条业务主链

1. **生产任务**：表单/文件创建 → 分组概览 → 游标分页列表 → 任务详情与六通道状态 → kill/clean → 回收站恢复或永久删除。
2. **版本配置**：按 model/video/prompt 通道筛选 → 创建或 UPSERT → JSON 配置详情 → 编辑或软删除。任务创建时冻结版本，之后的版本变更不追改历史任务。

任务级状态必须由六通道状态派生，不能由页面或普通写接口直接篡改。

## 前端页面骨架

```text
/llm-qc
├── tasks
│   ├── 分组概览与任务列表
│   ├── 创建任务：表单 / 文件上传
│   ├── 任务详情与六通道状态
│   └── 回收站
└── versions
    ├── 版本列表与通道筛选
    ├── 创建 / 编辑
    └── JSON 配置详情
```

模块专用交互包括：双向游标分页、六通道聚合、批量 kill/clean、恢复和永久删除。通用表格、抽屉、确认框、权限与异步反馈沿用 [[质检一站式平台顶层架构]]。
