# 人工质检验收第一纵切端到端架构

← [[人工质检验收第一纵切架构枢纽]]。

## 组件链

```text
AcceptanceQueueView
  → AcceptanceWorkbench
    → DataWorkbench
      → useTableState / TanStack Table
  → acceptanceApi.queryTasks / loadBreakdown
  → POST /api/v1/manual-qc/acceptance/tasks/query
  → AcceptanceQueryService
  → AcceptanceRepository
  → PostgresConnector
  → t_qc_delivery_task + t_qc_daily_snapshot
```

Vue 路由页只负责编排；公共表格状态放 `shared/data-workbench`；验收列定义和业务单元格放 `features/manual-qc/acceptance`。Router 不写 SQL，Service 不拼前端展示 HTML，Repository 不决定业务权限。

## 数据流

首屏只读聚合任务。用户展开任务时按需请求日期子行，不在首屏加载所有最小快照。筛选、排序和分页由后端执行；前端保存 QuerySpec 和布局状态。父行选择转换为叶子 SelectionSpec，第一纵切只显示批量操作入口，不调用真实 Delta。
