# 人工质检验收第一纵切验证计划

← [[人工质检验收第一纵切架构枢纽]]。

## 验证层级

1. PostgreSQL：migration、fixture、任务聚合 SQL 和日期展开固定结果；
2. Python 单元：QuerySpec 白名单、Repository 参数、Service 映射；
3. FastAPI：任务查询、日期展开、422/404/未实现维度；
4. Vue Vitest：父选子、子取消后父半选、分析面板默认隐藏、无选择不显示预览；
5. 浏览器：筛选、展开、跨页选择语义、视口横向滚动、深链和响应式。

第一纵切完成不能只看页面截图，必须有 PostgreSQL 固定聚合结果、API 响应断言和用户行为测试。

## 2026-07-05 首版验证证据

- `scripts/verify_acceptance_vertical_slice.sh`：隔离 PostgreSQL 实例验证 2 个任务、城区已提交 3500、3 个非连续日期明细；并执行 7 个 Python 测试；
- FastAPI：断言 Router 注册、统一 `ApiResponse`、查询分页与参数化过滤、日期明细响应；
- Vitest：2 个测试文件、4 个行为测试，覆盖父子选择、父半选、分析面板按需出现、预览主动触发；
- `vue-tsc --noEmit` 与 Vite production build 通过，122 modules transformed；
- `npm audit --audit-level=moderate` 为 0 vulnerabilities；
- 浏览器 DOM 与真实 API 200 已在首版联调中确认；最终自动截图因执行环境截图额度限制未重新生成，不用截图替代行为测试结论。
