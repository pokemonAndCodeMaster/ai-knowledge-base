# 质检一站式平台前端 Demo 设计计划

← 平台边界：[[质检一站式平台顶层架构]]。模块事实源：[[质检一站式平台人工质检模块整体架构]]、[[质检一站式平台大模型质检模块整体架构]]。

全局视觉、可访问性和动效硬规则见 [[质检一站式平台前端Demo设计规范]]。

## Demo 目标

用一个可离线打开的 HTML 原型证明统一平台壳层能承载两个差异明显的样板模块，并完整演示关键业务交互。它不是静态大屏，也不假装已接后端。

默认桌面优先，同时保证窄屏可浏览。首屏确定为平台总览；点击风险、待办或模块状态后进入带筛选上下文的模块页面。

## 页面范围

1. **平台总览**：模块健康、待处理事项、最近失败、数据新鲜度；卡片可进入具体模块并带入筛选。
2. **人工质检工作台**：交付中心、验收中心、人力与分组三个二级页。
3. **大模型质检工作台**：生产任务、版本配置两个二级页。
4. **规划中模块**：自动化质检、专题数据质量只展示边界说明，不虚构功能。

## 必须可操作的用户路径

### 人工质检

- 从交付列表筛选“我的/临期/阻塞”任务，打开交付详情抽屉，查看阶段、行动项和风险。
- 进入验收中心，选择日期、scene、组与策略；执行 preview，修改参数使旧 preview 失效；确认后 execute；查看成功、跳过、失败与回查中状态。
- 查看通过/打回规则结论；PENDING 时禁止执行；EXECUTE 权限下才能确认通过或打回。
- 在人力页按项目、供应商、角色筛选，展示人员单项目归属与未进组预警。

### 大模型质检

- 在任务组概览下钻任务列表，使用前后游标模拟分页，打开任务详情抽屉查看六通道状态。
- 创建任务时切换“表单创建/文件上传”，验证必填项和提交状态。
- 批量 kill/clean，显示作用范围、危险等级与部分失败结果。
- 进入回收站执行恢复或永久删除。
- 在版本页按 model/video/prompt 筛选，创建或编辑 JSON 配置，并查看任务创建时版本冻结的说明。

## 共享组件与状态

| 共享组件 | 责任 |
|---|---|
| AppShell | 一级模块、二级导航、用户权限、全局环境与帮助 |
| FilterBar | 结构化筛选、保存视图、重置、数据新鲜度 |
| DataTable | 列配置、排序、行选择、空态、加载态、错误态 |
| DetailDrawer | 保持列表上下文的任务/交付详情下钻 |
| StatusBadge | 状态文字、图标和颜色三重编码 |
| AsyncActionPanel | preview、执行、部分成功、失败与回查 |
| ConfirmDialog | 危险操作范围、数量、影响和确认 |
| Toast/InlineAlert | 即时反馈与可恢复建议 |

## 视觉方向草案

拒绝纯“大屏炫技”，采用密集但克制的运营控制台：浅色工作面为主，深墨色导航建立平台感。平台只有一套强调色和语义色，人工质检与大模型质检通过模块标签、图标和脉络条内容区分，不为每个模块另造一套色彩语法。

签名元素是“质检脉络条”：页面顶部用一条紧凑的阶段/通道轨道展示当前对象从输入到最终状态的全过程；人工模块显示交付阶段，大模型模块显示六通道进度。它编码真实流程，不作装饰。

## 设计拨盘与实现约束

- `DESIGN_VARIANCE: 5`、`MOTION_INTENSITY: 3`、`VISUAL_DENSITY: 8`。
- 参考 Carbon 的企业工作台密度和状态表达，但单 HTML 原型不冒充官方 Carbon 实现。

- 单文件 HTML + CSS + 原生 JavaScript，内置 Mock 数据，不依赖构建工具。
- 使用 CSS 变量定义色彩、间距、圆角、阴影与状态；SVG 图标统一线宽，不使用 Emoji 作为结构图标。
- 键盘可达、焦点可见、普通文本对比度至少 4.5:1；支持 `prefers-reduced-motion`。
- 375 / 768 / 1024 / 1440 四档检查；桌面信息密度高，移动端改为抽屉导航与卡片化明细。
- 动效只用于抽屉、弹窗、Toast、按钮按压和状态迁移，控制在 100-260ms；高频筛选和键盘导航不动画。

## 分阶段交付

1. **P0 对齐**：确认用户角色、首屏、真实通道名、Demo 深度和视觉方向。
2. **P1 骨架**：AppShell、平台总览、两模块路由与 Mock 数据层。
3. **P2 人工质检纵切**：交付详情 + 验收 preview/execute/refresh 完整交互。
4. **P3 大模型纵切**：任务列表/详情/六通道 + 版本配置 + 回收站。
5. **P4 体验收口**：响应式、键盘、错误/空态、动效与截图验收。

## 已冻结的 Demo 假设

- 第一屏是全平台运营总览。
- 六通道使用 `raw_img / label / pkl / video / prompt / inference` 及中文解释。
- 单 HTML 完全离线零依赖，图标使用同文件 SVG symbol sprite。
- 做高保真可点击原型，并模拟数据变化、异步进度、部分失败和状态回查。
