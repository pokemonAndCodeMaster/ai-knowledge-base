# 人工质检-①视频数据同步

> 从cog_fusion拉取视频数据，增量同步到视频中间表，自动触发GT去重检查和文本任务创建。

← [[人工质检-数据源与任务创建]] | [[人工质检-Hub]]

## 基本信息

| 维度 | 详情 |
|------|------|
| 核心代码 | `manual_label/human_inspection/sync_video_data.py` → `VideoSyncer`类 |
| DAG | `human_inspection_video_task`，每30分钟，max_active_runs=1，timeout=28min |
| 触发方式 | Airflow定时 + 手动调用 |

## 输入

| 数据源 | 完整表名 | 过滤条件 |
|--------|---------|---------|
| 视频数据 | `cog_fusion.public.t_general_unit` (pg_config) | `theme_id = {video_theme_id} AND create_time > '{start_time}'` |
| 旧文本排除 | 同上 | `theme_id NOT IN (100268, 100241, 160522, 160656, 160761, 160773)` |

## 输出

| 目标 | 完整表名 | 写入方式 |
|------|---------|---------|
| 视频中间表 | `app_gy1.pnc_simulation.t_video_task` (pg_config_app_gy1) | `INSERT ... ON CONFLICT (theme_id, data_uid, ide_task_id) DO NOTHING` |

## 处理逻辑

1. **`_pull_data()`**：增量拉取cog_fusion新数据，与t_video_task做差集
2. **`_insert_data()`**：分批查询cog_fusion详情，提取vis_interval，插入t_video_task
3. **`update_data()`**：回查cog_fusion状态变更(400=成功/300=失败)，更新t_video_task状态
4. **`_batch_process_gt_check_and_create_tasks()`**：**关键！** 对status=400的数据，自动执行GT去重+任务创建
   - 查 [[人工质检-数据表索引]] 检查已有GT
   - 查 [[人工质检-数据表索引]] 检查已有任务
   - 查 [[人工质检-数据表索引]] 检查cfg_ver合法性
   - IOU重叠检查 → 决定是否创建
   - 调用 [[人工质检-②文本任务创建]] 的 `insert_into_text_task()`

## 关键SQL

```sql
-- 增量拉取(排除旧文本主题)
WITH TABLE1 as (
    SELECT data_uid, input_data_version
    FROM public.t_general_unit
    WHERE theme_id = {video_theme_id} AND create_time > '{start_time}'
),
TABLE2 as (
    SELECT data_uid FROM public.t_general_unit
    WHERE theme_id IN (100268, 100241, 160522, 160656, 160761, 160773)
)
SELECT TABLE1.* FROM TABLE1 LEFT JOIN TABLE2 ON TABLE1.data_uid = TABLE2.data_uid
WHERE TABLE2.data_uid IS NULL;

-- 插入视频中间表
INSERT INTO pnc_simulation.t_video_task
(theme_id, data_uid, ide_task_id, input_data_version, status, create_time, update_time, obs_path)
VALUES (%s, %s, %s, %s, %s, %s, %s, %s)
ON CONFLICT (theme_id, data_uid, ide_task_id) DO NOTHING;
```
