# 人工质检-⑥标注与审核

> 标注员和审核员在Delta平台内部完成标注和审核操作，代码不直接参与，仅记录状态流转。

## Delta平台状态流转(筛选流)

```
64=待筛选 → 65=筛选中(标注员标注) → 66=待审核 → 67=审核中(审核员审核) → 68=待验收
```

## 状态枚举

→ [[人工质检-状态枚举与公共定义]]

## 标注员提交标注时

- 状态从65→66(待审核)
- `behavior_status`字段写入标注结果JSON
- Delta审核记录表写入 `old_status=30, new_status=40` 记录

## 审核员审核时

- 状态从67→68(待验收) — 审核通过
- 或状态从67→退回 — 审核打回
