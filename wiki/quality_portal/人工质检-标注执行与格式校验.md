## Delta平台状态流转(筛选流)

```
64=待筛选 → 65=筛选中 → 66=待审核 → 67=审核中 → 68=待验收 → 69=验收中 → 70=已完成
```

## 格式校验判定规则

1. `lost_num > 0` → 必填题缺失 → 打回
2. `break_rules` 非空 → 违反关系约束 → 打回
3. 子片段时长 < 2秒 → 人工标注区间异常 → 打回

打回方式：`CreatorBase.revert_bad_label_task()` → Delta平台 `taskRollback` API
