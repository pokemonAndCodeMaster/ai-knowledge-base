# 质检平台采样与规则引擎导航

← 总入口：[[质检一站式平台人工质检模块整体架构]]。

本卡只做采样与规则子域导航。两者都使用代码注册表，但输入、输出和副作用边界不同，不再塞进同一张巨型设计卡。

| 子卡 | 关注问题 |
|---|---|
| [[质检平台-验收采样配额与任务选择设计]] | 快照如何计算配额、如何取得具体 task_ids、三种采样策略和不足补齐 |
| [[质检平台-通过打回规则与执行设计]] | 完成度、Good/Bad 阈值、PENDING/PASS/REJECT、平台执行和状态回查 |
| [[质检平台-综合快照表设计]] | 两类引擎共同使用的统计计数和最小粒度 |
| [[质检平台-Delta调用与状态回查设计]] | 两类引擎产生结论后如何执行并确认实际结果 |
| [[质检平台-领域模型层设计]] | 策略输入输出的数据结构如何就近定义和复用 |

共同原则：

- 注册表是策略名称唯一事实源，不重复维护 Name Enum；
- 规则类不查数据库、不调用 Delta；
- Service 负责编排，Repository 负责 task/快照读取；
- preview 展示解释，execute 执行前重查状态；
- 实际成功量以状态回查为准。
