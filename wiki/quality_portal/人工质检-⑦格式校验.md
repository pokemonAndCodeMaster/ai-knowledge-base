# 人工质检-⑦格式校验

> 自动检查审核/验收阶段任务的标注格式，不合格任务自动打回。

← [[人工质检-标注执行与格式校验]] | [[人工质检-Hub]]

## 基本信息

| 维度 | 详情 |
|------|------|
| 核心代码 | `manual_label/human_inspection/check_label_format.py` → `CheckFormat`类 |
| DAG | `human_inspection_check_format`，每15分钟，max_active_runs=1，timeout=14min |
| 触发方式 | Airflow定时 |

## 输入

| 数据源 | 完整表名 | 过滤条件 |
|--------|---------|---------|
| DI任务+标注+内部任务 | 三表联查 | `di_task.task_status IN (66,67,68,69)` |

## 输出

| 目标 | 说明 |
|------|------|
| Delta API | `CreatorBase.revert_bad_label_task()` → taskRollback打回 |

## 判定规则

| 规则 | 条件 | 说明 |
|------|------|------|
| 必填题缺失 | `lost_num > 0` | 存在未按要求格式填写的题目 |
| 关系约束违反 | `len(break_rules) > 0` | 违反TextParser的共存/互斥规则 |
| 子片段时长不足 | `subclip时长 < 2秒` | 仅当interval_source='human'且text_items>1时检查 |

## 关键SQL

```sql
SELECT sdobj.behavior_status AS gt, sdobj.task_id AS task_id,
    task.cfg_ver AS cfg_ver, task.metadata->>'interval_source' AS interval_source
FROM delta.ods_t_label_screening_task_datalake AS di_task
    INNER JOIN delta.ods_t_label_sdobject_datalake_new AS sdobj ON di_task.id = sdobj.task_id
    INNER JOIN pnc_simulation.t_text_label_task AS task ON di_task.task_name = task.task_name
WHERE di_task.task_name LIKE '%{project}%'
AND di_task.del_flag = 0 AND di_task.task_status IN (66,67,68,69)
AND task.cfg_ver IS NOT NULL;
```
