# src/ 顶层架构总览

项目代码库已从 `tool_registry/` 三层架构（atomic/common/domains）迁移至 `src/` 二级扁平架构。本卡描述新架构的包结构与职责映射。

## 架构变迁

| 维度 | 旧架构 (`tool_registry/`) | 新架构 (`src/`) |
|------|--------------------------|----------------|
| 层级数 | 三层（atomic/common/domains） | 二级扁平（src/{package}） |
| 按技术分层 | atomic(原子能力)/common(通用能力)/domains(领域应用) | 按业务域扁平组织 |
| 跨层引用 | 需通过 adapters 适配层 | 直接 import，无需适配 |
| 复杂度 | 高（3层+1适配层） | 低（2级目录） |

## 新架构包结构

```
src/
├── config/          # 统一配置管理（原 tool_registry/common/config/）
│   ├── config_loader.py   # ConfigManager + ConfigValidator 核心实现
│   └── __init__.py
│
├── obs/             # OBS 存储操作（原 tool_registry/atomic/storage_ops/）
│   ├── obs_manager.py     # ObsManager 高层封装
│   ├── obs_client.py      # ObsClient 底层 moxing 封装
│   └── __init__.py
│
├── database/        # 数据库连接器（原 tool_registry/atomic/db_connectors/）
│   ├── pg_connector.py    # PostgreSQL 连接器（含内联生命周期方法 + DatabaseConfig 桥梁）
│   └── __init__.py
│
├── clipinfo/        # Clip 信息与数据转换（原 tool_registry/atomic/data_handlers/ + common/data_utils/ + common/metadata/）
│   ├── models.py          # ClipInfo/ClipInfoCollection 数据模型
│   ├── service.py         # ClipService 门面 + FragmentNotFoundError + PklResolution
│   ├── batch_download.py  # BatchDataDownloader + TimingStats
│   ├── label/             # 标签操作
│   │   ├── query.py       # BatchLabelQuery + LabelVersionResult + QueryResult
│   │   ├── parquet.py     # ParquetConverter + numpy_encoder + extract_timestamps + convert_string_format

│   │   └── frenet.py      # Frenet 坐标转换（统一了三处实现：sl2xy_pos, xy2sl_pos, get_proj_point, pts_cartesian_to_sl）
│   ├── cam/               # 摄像头图片操作（占位）
│   └── __init__.py
│
├── llm/             # LLM 数据生产与任务调度（原 tool_registry/domains/llm_tools/ + domains/task_scheduler/）
│   ├── video.py           # VideoProduction 视频生产编排器

│   ├── inference.py       # LLMInference 推理编排器
│   ├── formatter.py       # DatasetFormatter 数据集格式化器
│   ├── config.py          # VideoConfig/VideoLayout/VideoTask/ExchangeRecord
│   ├── timing.py          # TimingCollector 时延收集器
│   ├── scheduler.py       # TaskWorker + TaskSchedulerApp 调度入口
│   ├── task_repository.py # TaskRepository DB 读写封装
│   ├── task_creator.py    # TaskCreator 任务创建器
│   ├── task_query.py      # TaskQueryService 聚合查询
│   ├── dedup_lock.py      # DedupLock 去重锁
│   ├── watchdog.py        # Watchdog 守护进程
│   ├── exceptions.py      # LLM 域异常定义
│   └── __init__.py
│
├── pkl_vis/         # PKL 可视化引擎（原 tool_registry/domains/pkl_vis/）
│   ├── run.py              # generate_video() 统一入口
│   ├── canvas_wrapper.py   # vispy Canvas 封装
│   ├── video_data_loader.py # 帧数据加载
│   ├── data_source.py      # JSONL 数据源
│   ├── local_cam_source.py # 纯 cam 数据源
│   ├── load_szt_data.py    # OBS zst 数据源
│   ├── load_download_pkl.py # 本地 pkl 数据源
│   ├── frame_data.py       # FrameData 帧数据门面
│   ├── vis_factory.py      # 可视化器工厂
│   ├── cam_projection/     # 坐标变换与相机投影
│   ├── visualizer/         # ~30 个可视化器
│   ├── default_config.json # 默认布局配置
│   └── __init__.py
│
├── data_check/      # 数据质检引擎（已迁移至 src/data_check/）
│   └── ...                # 详见 [[HUB-质检引擎层架构]]
│
└── __init__.py
```

## 旧路径 → 新路径映射表

| 旧路径 | 新路径 | 说明 |
|--------|--------|------|
| `tool_registry/atomic/storage_ops/` | `src/obs/` | OBS 存储操作 |
| `tool_registry/atomic/db_connectors/` | `src/database/` | 数据库连接器 |
| `tool_registry/atomic/data_handlers/` | `src/clipinfo/` | 数据处理器（ParquetConverter 等） |
| `tool_registry/common/config/` | `src/config/` | 统一配置管理 |
| `tool_registry/common/data_utils/` | `src/clipinfo/` | 数据工具（合并入 clipinfo） |
| `tool_registry/common/metadata/` | `src/clipinfo/` | 元数据管理（合并入 clipinfo） |
| `tool_registry/domains/llm_tools/` | `src/llm/` | LLM 工具 + 任务调度 |
| `tool_registry/domains/task_scheduler/` | `src/llm/` | 任务调度（合并入 llm） |
| `tool_registry/domains/pkl_vis/` | `src/pkl_vis/` | PKL 可视化引擎 |
| `tool_registry/adapters/` | 已删除 | 适配层不再需要 |
| `tool_registry/examples/llm_tools/` | `examples/llm/` | 示例脚本 |
