# 人工质检-数据源与任务创建

> 人工质检流程的第一阶段：从视频数据源接入到标注任务创建并发送至Delta平台。

← [[人工质检-Hub]]

## 步骤清单

| 步骤 | 名称 | 核心代码 | DAG | 详细卡片 |
|------|------|---------|-----|---------|
| ① | 视频数据同步 | `human_inspection/sync_video_data.py` → `VideoSyncer` | `human_inspection_video_task`(30min) | [[人工质检-①视频数据同步]] |
| ② | 文本任务创建 | `human_inspection/dag_run.py` → `insert_into_text_task()` | Step①自动触发 | [[人工质检-②文本任务创建]] |
| ③ | 预标注+LLM/FDE决策 | `human_inspection/create_label_task.py` → `TaskCreator.run()` | `human_inspection_text_task`(30min) | [[人工质检-③预标注与LLM决策]] |
| ④ | Delta平台创建任务 | `create_base.py` → `CreatorBase.send_post_request()` | Step③内调用 | [[人工质检-④Delta平台创建任务]] |
| ⑤ | 任务分配 | `label_task_manage/assign_quality_check.py` → `ListAssign()` | 手动 | [[人工质检-⑤任务分配]] |

## 数据流转

```
cog_fusion.t_general_unit
  → [①] pnc_simulation.t_video_task
  → [②] pnc_simulation.t_text_label_task (pending)
  → [③] 预标注填充 + LLM/FDE决策
       ├── good → 打桩(finished, who_label=1/3/4/5)
       └── 非good → who_label=0(human)
  → [④] Delta平台API → waitingAssign(0)
  → [⑤] 批量分配screener/reviewer/acceptor → waitingFilter(64)
```

## 关键决策点

- **LLM+FDE分流**：autochecker+LLM+FDE都good → 跳过人工(打桩)；否则 → 走人工
- **GT去重**：新建任务前检查 vis_interval 与已有GT/任务的IOU重叠
- **cfg_ver校验**：不存在的cfg_ver直接跳过不创建
