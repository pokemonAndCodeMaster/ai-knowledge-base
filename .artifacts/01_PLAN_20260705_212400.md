# 人工质检验收第一纵切首版交付计划

## 目标

在不使用商业授权的前提下，形成 Vue3 + FastAPI + PostgreSQL 的完整首版纵切，并让设计可从单一枢纽卡逐层 Review。

## 范围

1. 冻结开源前端栈与 PostgreSQL preview 决策；
2. 建立第一纵切 Hub、端到端架构、数据、API、前端和验证卡片层级；
3. 实现任务聚合、按日展开、统一响应、测试表与 fixture；
4. 实现 AppShell、统一 DataWorkbench、DashboardLayout 和验收队列；
5. 验证父子选择、分析按需出现、预览主动触发、数据库聚合与 production build。

## 暂不包含

- 真实 Delta execute；
- 真实 SSO；
- 完整 SelectionSpec/preview 服务；
- 全部高级筛选、编辑、导出和布局持久化。
