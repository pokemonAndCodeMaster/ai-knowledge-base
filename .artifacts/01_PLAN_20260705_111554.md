# 质检业务总览与人工质检总览重设计计划

## 目标

- 纠正平台的 OneTrack 权限模型，删除显式角色切换。
- 将首页改为团队视角的“质检业务总览”，浓缩人工、自动化、大模型和专题数据质量。
- 将人工质检总览设计为需求接纳与交付推进工作台。
- 从头设计浅色、高密度的业务账本视觉，不继承旧 Demo 的外观。
- 将业务结论回写到平台、模块、权限、交付中心与前端设计卡片。

## 实施范围

1. 新建质检业务总览和人工质检总览信息架构卡。
2. 联动修改顶层架构、四业务模块、SSO 权限、人工交付机制与前端规范。
3. 重写 `demo/quality-check-platform.html`，提供五个总览落点，优先完成业务总览和人工质检总览。
4. 执行静态解析、真浏览器桌面/移动端截图、交互回归和知识图谱验证。

## 成功标准

- 界面无管理者/运营人员切换。
- 首页能同时表达近期交付质量、四业务现状和里程碑。
- 人工质检总览按需求接纳、倒排、标注、验收、可交付的顺序呈现。
- 周度/双周/月度窗口会同步更新标题、数量和风险说明。
- 新卡可被图谱检索，不产生新孤岛。
