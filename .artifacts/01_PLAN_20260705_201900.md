# 质检平台统一工作台与模块扩展计划

## 目标

把散落在各页的表格和 panel 收敛为统一数据工作台与可配置卡片布局，并用该底座深化验收中心、大模型生产任务、专题、自动化质检和大模型下级页。

## 组件契约

- 数据工作台：列筛选/排序/显隐/编辑/宽度、列组、层级行、多选批处理、导出、分页、镜像横向滚动、布局保存、一键统计分析。
- 卡片布局：公共/个人布局，新增/复制/移动/缩放卡片，图表原子组合，筛选快照和上下文下钻。
- 高风险操作：选择范围 → 规则/参数 → 预览 → 局部排除/覆盖 → 执行 → 回查 → 审计。

## 页面范围

- 验收：任务队列、分配、通过打回、质量分析。
- 大模型：总览、生产任务、版本、数据集、模型评测。
- 自动化：质检项能力、配置、版本、结果分析。
- 专题：总览及城区、高速、园区、感知、仿真页。
